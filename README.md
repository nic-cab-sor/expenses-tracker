Title : ExpensesTracker

Functionality :
    - Track expenses by allowing the user to add, modify and remove expense entries.
    - Auto calculate the total cost of all expenses for a specific date range.
    - Auto calculate money left after deducting the total cost of all expenses from the income for that date range.
    - Track what expenses have already been paid.
    - Track due dates of expenses.
    - Categorise by using header separator lines.
